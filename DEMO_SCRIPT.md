2. Run `./scripts/start-frontend.ps1`; open `http://127.0.0.1:5173`.
3. Say: “The gallery is API-backed and currently contains 320 preserved projects in 20 domains.”
4. Search for `phishing`, filter Cybersecurity, change the sort order, then open a detail modal.
5. Register a presentation account with a strong password, sign in, publish a short project, and edit that same project.
6. Open a project created by another account and demonstrate the owner-only action is rejected.
7. Open `http://127.0.0.1:8000/docs`, execute the safe GET endpoints, and show `/health`.
8. Show `TEST_RESULTS.md`, then `artifacts/load-tests/local-benchmark.json`.
